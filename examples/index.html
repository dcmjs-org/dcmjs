dcmjs 1.0

DICOM in JavaScript, for the browser and for Node. dcmjs 1.0 is a system of libraries: you read, write, convert, send and show medical images with packages that work together, and you install only the packages that you need. 

npm install @dcmjs-org/dcmjs

Read the (draft) 1.0 announcement GitHub

The system

The dcmjs packages are the base. The tools and the network libraries use the packages. The viewers and the servers use all of them.

1. The dcmjs packages
Read and write DICOM Part 10 files and DICOMweb JSON. Work with datasets as plain JavaScript objects.
2. Tools, network and codecs
A command line and an MCP server, a DICOMweb client, DIMSE networking, and the image codecs.
3. Libraries and applications
Cornerstone3D, the OHIF Viewer and Static-DICOMweb use dcmjs for their DICOM data.

1. The dcmjs packages

@dcmjs-org/dcmjs has the same export names as dcmjs 0.52, so most projects change only the import line. The migration guide and the list of breaking changes give the changes from 0.x.

Package What it does
@dcmjs-org/dcmjs The complete library, with the export names of dcmjs 0.x. Start here.
@dcmjs-org/core The shared parts: value representations, tags, the dictionary, character sets, naturalized datasets and frameDataset.
@dcmjs-org/legacy The readers and writers of 0.x: DicomMessage, DicomDict and AsyncDicomReader.
@dcmjs-org/parser The streaming reader. It reads files that are larger than memory.
@dcmjs-org/generator The streaming writers for Part 10 files and DICOMweb JSON.
@dcmjs-org/schemas The catalog of DICOM attributes, with names, types and rules.
@dcmjs-org/dicomdir Reads and writes DICOMDIR.
@dcmjs-org/encapsulated Puts a PDF into a DICOM instance, and gets it out again.
@dcmjs-org/imaging Builds an image instance from decoded pixels, with no codec.
@dcmjs-org/video Puts an MP4 video into a DICOM instance without a new encode.
@dcmjs-org/media One package that has dicomdir, encapsulated, imaging and video.
@dcmjs-org/fhir Maps DICOM to FHIR resources.

2. Tools, network and codecs

dcmjs-commands
The command line of dcmjs 1.0, and an MCP server for AI agents. It can dump, validate, convert, anonymize and transcode files, resize whole-slide images, make enhanced multi-frame images, and write DICOMDIR and Static-DICOMweb output.
dicomweb-client
A client for DICOMweb servers: QIDO-RS, WADO-RS and STOW-RS.
dcmjs-dimse
DIMSE networking for Node: C-ECHO, C-FIND, C-STORE, C-MOVE and C-GET.
Cornerstone codecs
WebAssembly image codecs for the DICOM transfer syntaxes, for example JPEG, JPEG-LS, JPEG 2000, HTJ2K and JPEG XL.

3. Libraries and applications that use dcmjs

Cornerstone3D
A library for medical image display and annotation in the browser. Its adapters use dcmjs to read and write SEG, SR and RTSTRUCT.
OHIF Viewer
A web viewer for medical images, built on Cornerstone3D and dcmjs.
Static-DICOMweb
Makes and serves DICOMweb data as static files. It uses dcmjs to read the DICOM input.
